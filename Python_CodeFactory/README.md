# Python CodeFactory — Basics to Advanced

A structured, classroom-friendly Python curriculum and code library. Each topic has a clear folder name, a teaching note, runnable examples, and exercises where appropriate.

## Who this is for
- Students learning Python from first principles
- Teachers who want a consistent lesson sequence
- Learners progressing from core syntax to files, OOP, testing, APIs, databases, concurrency, and project design

## Requirements
- Python 3.10+ recommended
- A code editor such as VS Code
- Terminal / PowerShell

Check Python:
```bash
python --version
```
Run an example from the project root:
```bash
python 01_python_fundamentals/01_hello_python/main.py
```

## Folder convention
Each numbered topic contains:
- `README.md` — lesson goals, explanation, run instructions, and teaching notes
- `main.py` — runnable example (or a focused module)
- `exercises.md` — student practice tasks, when useful

Examples are intentionally small and dependency-free unless the lesson explicitly explains an optional dependency.

## Suggested classroom routine
1. Explain the lesson goals and vocabulary.
2. Live-code the example and predict the output before running it.
3. Ask students to modify one thing at a time.
4. Assign exercises from easy to challenging.
5. Review readability, edge cases, and tests—not only whether the code runs.

## Good habits taught throughout
- Use meaningful names and small functions.
- Keep side effects visible.
- Validate inputs and handle errors deliberately.
- Prefer the standard library before adding dependencies.
- Never put passwords, tokens, or private keys in source code.
- Test edge cases and explain assumptions.

## Note
This is a teaching starter library, not a substitute for a full Python language reference. Add lessons and solutions as your class advances.
