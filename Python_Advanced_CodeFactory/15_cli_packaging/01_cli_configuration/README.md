# CLI and Configuration

## Why this matters
Professional CLI tools provide help, clear arguments, predictable behaviour, and configuration separated from business logic. Keep secrets out of source control and command history.

## Run
From the project root, run:
```bash
python 15_cli_packaging/01_cli_configuration/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
