# Defensive Security Engineering

## Why this matters
Secure design identifies assets, trust boundaries, threats, and mitigations. Validation is not authorization. Use least privilege, parameterized SQL, safe logging, and environment-based secrets. This lesson is defensive and local.

## Run
From the project root, run:
```bash
python 14_security/01_defensive_validation/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
