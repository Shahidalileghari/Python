# Protocols and Structural Typing

## Why this matters
Protocols describe required behaviour without forcing inheritance. Generics preserve type relationships. Type hints improve tooling and readability but do not automatically validate every runtime value.

## Run
From the project root, run:
```bash
python 04_advanced_typing/01_protocols/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
