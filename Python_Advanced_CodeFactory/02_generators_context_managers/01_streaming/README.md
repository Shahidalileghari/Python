# Generators and Context Managers

## Why this matters
Generators produce values on demand. Context managers release resources even if exceptions occur. Streaming can reduce peak memory usage, but measure the real workload before claiming it is faster.

## Run
From the project root, run:
```bash
python 02_generators_context_managers/01_streaming/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
