# Profiling and Complexity

## Why this matters
Optimize based on measurement, not intuition. Big-O helps reason about growth; profiling identifies real bottlenecks. Always preserve correctness and benchmark representative inputs.

## Run
From the project root, run:
```bash
python 08_performance/01_profiling/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
