# Logging and Health Checks

## Why this matters
Logs should help diagnose behaviour without exposing credentials or personal data. Health checks should be cheap and avoid revealing internal secrets. Distinguish liveness from readiness.

## Run
From the project root, run:
```bash
python 16_observability/01_logging_health/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
