# Capstone: Student Gradebook

A small starter project that demonstrates functions, validation, JSON persistence, and calculated summaries.

Run from the project root:
```bash
python 22_capstone_projects/student_gradebook/main.py
```

The demo adds a sample student each time it runs, so the file grows on repeated runs. As an extension, add duplicate detection, a command-line menu, edit/delete features, and unit tests. Use fictional student records only.
