# Fakes, Mocks, and Test Boundaries

## Why this matters
Use fakes to replace dependencies in unit tests. Mock interactions only when the interaction itself matters. Unit tests complement, rather than replace, integration tests.

## Run
From the project root, run:
```bash
python 07_testing_advanced/01_fakes/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
