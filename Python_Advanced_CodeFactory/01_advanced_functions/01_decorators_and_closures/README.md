# Decorators and Closures

## Why this matters
Decorators wrap behaviour without changing a function's call site. Closures retain values from an enclosing scope. `functools.wraps` preserves useful metadata. Keep decorators small and avoid hiding important control flow.

## Run
From the project root, run:
```bash
python 01_advanced_functions/01_decorators_and_closures/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
