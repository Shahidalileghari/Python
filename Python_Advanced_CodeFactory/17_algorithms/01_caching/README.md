# Caching and Complexity

## Why this matters
Caching avoids repeated computation but adds memory use and invalidation concerns. Cache only stable results and define lifetime and isolation rules. Never cache secrets or user-specific data without a safe design.

## Run
From the project root, run:
```bash
python 17_algorithms/01_caching/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
