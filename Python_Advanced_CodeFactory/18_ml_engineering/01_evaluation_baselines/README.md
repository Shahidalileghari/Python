# ML Engineering Foundations

## Why this matters
Reliable ML systems need validated data, reproducible splits, baselines, metrics, versioning, and monitoring. Keep test data separate to avoid leakage. This toy lesson uses only the standard library, not a training framework.

## Run
From the project root, run:
```bash
python 18_ml_engineering/01_evaluation_baselines/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
