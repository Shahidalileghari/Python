# Dependency Injection

## Why this matters
Dependency injection makes collaborators explicit and replaceable. It helps unit tests use fakes rather than external services. Keep interfaces small and avoid unnecessary abstractions.

## Run
From the project root, run:
```bash
python 05_architecture/01_dependency_injection/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
