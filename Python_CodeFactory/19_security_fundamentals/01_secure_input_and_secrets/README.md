# Security Fundamentals

## Learning objectives
Treat input as untrusted, avoid secrets in source, and use safe APIs.

## Key concepts
- Read the code from top to bottom before executing it.
- Identify the inputs, processing steps, and outputs.
- Change one part, predict the result, then run it.
- Consider invalid input and edge cases.

## Run
From the project root:
```bash
python 19_security_fundamentals/01_secure_input_and_secrets/main.py
```

## Teaching notes
1. Ask learners to explain each line in their own words.
2. Ask what might go wrong if the input or state changes.
3. Invite a small extension before assigning the exercises.

## Completion check
A student should be able to explain the example, run it independently, and solve at least two exercises without copying the solution.
