# Streaming ETL Pipeline

## Why this matters
ETL means Extract, Transform, Load. Streaming makes memory use more predictable and forces explicit validation. Decide how invalid records are reported and whether processing can continue.

## Run
From the project root, run:
```bash
python 13_data_engineering/01_streaming_etl/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
