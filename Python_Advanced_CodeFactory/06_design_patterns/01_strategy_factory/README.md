# Strategy and Factory Patterns

## Why this matters
Strategy encapsulates interchangeable behaviour. A factory centralizes object creation when selection rules become nontrivial. Patterns are tools, not rules; prefer the simplest design that fits the requirement.

## Run
From the project root, run:
```bash
python 06_design_patterns/01_strategy_factory/main.py
```

## Teaching method
Predict the output, run the example, modify one assumption, then explain the trade-off.
